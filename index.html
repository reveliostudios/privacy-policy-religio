Política de Privacidade

Última atualização: 18 de abril de 2026

1. Informações gerais

Este jogo, Religio: Simulador de Fé, é desenvolvido por Revelio Studios. Esta Política de Privacidade explica como dados são coletados, usados e protegidos.

2. Coleta de dados

O aplicativo pode coletar automaticamente os seguintes dados:

  • Identificadores de dispositivo (como Advertising ID)
  • Dados de uso do aplicativo (tempo de jogo, interações)
  • Dados de desempenho (crashes e diagnósticos)

Esses dados podem ser coletados por serviços de terceiros como Google AdMob e Google Play Services.

3. Uso dos dados

Os dados coletados são usados para:

  • Exibição de anúncios (Google AdMob)
  • Melhorar a experiência do jogo
  • Análise de desempenho e correção de falhas
  • Prevenção de fraudes e segurança

4. Compartilhamento de dados

Os dados podem ser compartilhados com serviços de terceiros, incluindo:

  • Google AdMob (publicidade)
  • Google Play Services

Não vendemos dados pessoais dos usuários.

5. Armazenamento de dados

Os dados são armazenados por tempo necessário para funcionamento do aplicativo ou conforme exigido por serviços terceiros.

6. Exclusão de dados

O usuário pode solicitar a exclusão de seus dados entrando em contato pelo e-mail abaixo:

suporte: reveliostudios@gmail.com

7. Segurança

Utilizamos serviços seguros e criptografados fornecidos pelo Google para proteger os dados dos usuários.

8. Privacidade de crianças

O jogo não é direcionado a crianças menores de 13 anos.

9. Alterações nesta política

Esta política pode ser atualizada a qualquer momento. Recomenda-se revisão periódica.
